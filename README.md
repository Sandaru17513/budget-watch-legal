# Budget Watch legal pages

Static Privacy Policy and Terms of Use for Budget Watch, served by GitHub Pages at `/privacy/` and `/terms/`.

The text comes from the app's `data/legal.ts` (only `privacyPolicy` and `termsOfUse` are published).

## Update

1. Edit `data/legal.ts` in the app repo.
2. Run `node build.mjs` here (Node 22.18+; optional path argument, default `../Budget-Watch/data/legal.ts`).
3. Commit and push this repo.
